# `app/core/` — Core Engine, Tool Contracts & Reactive Orchestration

## 1. Directory Role & Boundary
The `app/core/` directory provides the fundamental contracts, execution runtime, and reactive event-driven pipeline system for the Jarvis ecosystem. It contains zero domain-specific tools, serving strictly as the operational foundation.

## 4. Universal Tool Contract (`BaseTool`)
All executable actions in Jarvis implement `BaseTool`:

```python
class BaseTool(ABC):
    name: str
    description: str
    risk_level: RiskLevel = RiskLevel.LOW
    category: str = "tool"  # "tool" | "skill" | "pipeline"

    @abstractmethod
    async def execute(self, **kwargs) -> ToolResult:
        ...
```

---

## 5. Critical Invariants
* **Non-Blocking Execution**: Tools executed by `ExecutionEngine` must be async (`async def execute`). CPU-bound or blocking operations must run via `asyncio.to_thread`.
* **Path Safety Boundary**: Tools operating on the filesystem must check paths against protected boundaries and refuse destructive modifications outside the active workspace.
* **Reactive Downstream Chaining**: When a plan contains `[fork, tool_b, tool_c]`, `_fork_task` registers `tool_b` and `tool_c` with `TaskChainOrchestrator`. Downstream steps execute reactively when the worker emits `WORK_COMPLETED`.
